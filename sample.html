About this design system

This file, together with style.css, documents the visual language used across IPLUG's HTML email campaigns (core_team.html, final_draft.html, reminder.html, thanks.html). If you only have these two files, you have everything needed to understand — or generate new — emails that match the existing set.

BrandIPLUG — the technology, computing & gaming club at IISER Pune
FormatDark-mode-only HTML emails, table-based layout for email-client compatibility (Outlook/mso conditionals, role="presentation" tables, inline-safe structure)
Visual motifDeveloper / terminal aesthetic — command-line prompts (">"), code comments ("// like this"), monospace labels, boot-sequence / progress-bar flourishes, file-path-style captions (e.g. "./code_module.py")
Voice & toneCasual, geeky, slightly playful. Copy leans on programming metaphors ("compiling ideas", "system ready", "awaiting your next commit") without being a gimmick — headings and CTAs stay clear and direct
Two colour themesSee section 2 & 3 below — both are dark, near-black backgrounds with a single green accent, just different exact hues/panels
TypographyMonospace for labels/eyebrows/code bits, a geometric display sans for headlines, a plain system sans for paragraph copy — see section 1
Recurring componentsTerminal-chrome window, quote/callout block, numbered task-list rows, chip/pill links (WhatsApp / Discord / Instagram), highlighted deadline box, footer sign-off card with logo + social chips — see sections 4–13
LogoSingle square mark, shown above and reused at 88px (header) / 70px (footer sign-off) throughout every email — embedded inline below and in style.css consumers as base64 PNG

15. Logo — the single mark used across every IPLUG email

Shown at 88px in email headers and 70px in footer sign-off cards.

Embedded inline as a base64 PNG (data:image/png;base64,...) so it renders without external image hosting or a "load images" prompt in email clients.

Same logo file is reused, byte-for-byte identical, in every one of the four emails.

Some emails (final_draft.html / reminder.html / thanks.html) additionally define a .logo-light-img / .logo-dark-img pair on the same mark, so a colour-scheme-aware mail client could in principle swap logo variants — currently both point at the same dark-optimised PNG.

16. Responsive utilities — @media (max-width: 620px)

.wrap / .fluid — force full width on mobile

.stack — collapse two-column layouts to stacked blocks

.pad-mobile — tighter side padding on small screens

.hero-title / .h2-title — smaller headline sizes on mobile

.divider-v — hide vertical dividers on mobile

.sign-text / .chip-row — center sign-off text and chip row on mobile
